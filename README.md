# テニス夜間空き通知

依頼された日だけ、当日の豊川公園庭球場・コート1〜12の夜間を5分間隔を指定して確認します。
指定した終了時刻以降は新しい確認・通知を行いません。翌日は自動再開しません。
現在の対象日はwatch.pyのWATCH_DATEに記載されています。
次回、ChatGPTへ「今日の夜間コートを確認して」と依頼した際に、その日の日付へ変更して開始します。会話での依頼を自動受信する機能ではなく、ChatGPTが設定を変更して再開します。

## 開始・停止
開始：watch.pyのWATCH_DATEを対象日（YYYY-MM-DD）に設定。MONITOR_ENABLED=trueが必要です。
即時停止：Settings → Secrets and variables → Actions → VariablesでMONITOR_ENABLEDをfalseへ変更。
定期実行枠は毎日日本時間9:02〜17:57の5分間隔ですが、対象日以外はサイトにアクセスせず終了します。
無料GitHub Actionsでは混雑による遅延・スキップがあり、5分以内の検知を保証しません。
公開プロジェクトに60日間操作・変更がないと定期実行が無効になる場合があります。

## 非公開の通知設定
TENNISU：送信元Gmail
TENISU2：通知先Gmail
TENISU3：送信元Gmailのアプリパスワード
これらはRepository Secretsに登録し、公開ファイルには記載しません。
